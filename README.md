## The verification track (`ligo_backaction`)

Simulation code for the project *"use the channel description to test QFI for
states under radiation pressure"*: how much information about a
gravitational-wave strain survives in an optical state once ponderomotive
back-action, optical loss and phase noise have acted on it, and which probe
states hold up best at fixed photon number.

Everything is built around a single object, a **channel specification**, and a
single interface, a **pure function `(state, params) -> rho_out`** — so the same
pipeline can be driven from the Fock-space (non-Gaussian) track or the Gaussian
(covariance-matrix) track, and later from a different array backend.

```python
from ligo_backaction import ChannelSpec, make_state, qfi_lambda

psi  = make_state("squeezed", N=200, nbar=2.0)          # fixed <n>
spec = ChannelSpec(kappa=1.5, ordering="BA1", eta_out=0.9)
qfi_lambda(psi, spec)                                    # -> 4.3539
```

## Physics and conventions

With `hbar = 1`, `x = (a + a†)/sqrt(2)`, `p = (a - a†)/(i sqrt(2))`, the vacuum
has `Var = 1/2`. The Kimble *et al.* two-photon quadratures map on as
`a1 = sqrt(2) x`, `a2 = sqrt(2) p`, so the free-mass input–output relation

```
b1 = a1,        b2 = a2 - kappa a1 + sqrt(2 kappa) h / h_SQL
```

becomes, in this package's quadratures,

```
x -> x,         p -> p - kappa x + lambda,      lambda = sqrt(kappa) h / h_SQL
```

Radiation pressure is therefore the **shear** `S = [[1, 0], [-kappa, 1]]`,
generated by the unitary

```
U_BA(kappa) = exp(-i kappa x² / 2)
```

and the signal is a **displacement along p**, generated by `x`:

```
U_sig(lambda) = exp(+i lambda x)
```

`shear_to_squeeze_rotation(kappa)` gives the equivalent
rotation–squeeze–rotation decomposition, with `e^r - e^-r = kappa`.

The QFI is reported in two units:

* `qfi_lambda` — for the dimensionless displacement `lambda`;
* `qfi_strain` — for the strain, `F_h = (kappa / h_SQL²) F_lambda`, so the
  Cramér–Rao bound is `sigma_h >= F_h^(-1/2)`.

For vacuum input, `F_lambda = 2` and `sigma_h >= h_SQL / sqrt(2 kappa)`, which
is exactly the noise of the frequency-dependent ("variational") homodyne
readout — a good sanity anchor, and a unit test.

### Channel orderings

| `ordering` | pipeline |
|---|---|
| `none` | signal only (reference, no radiation pressure) |
| `BA1`  | radiation pressure → displacement sensing |
| `BA2`  | displacement sensing → radiation pressure |
| `BA3`  | simultaneous, `exp(-i(kappa x²/2 - lambda q_phi))` — the physical case |

The full pipeline is

```
input -> phase noise (in) -> injection loss -> [BA / signal] -> phase noise (out) -> detection loss
```

`phi_sig` rotates the signal quadrature; `phi_sig = 0` is the physical free-mass
case in which the signal generator commutes with the back-action generator.

## Numerical practicalities

**The Fock cutoff is the whole ballgame.** The shear multiplies the `p`
variance by `1 + kappa²`, so the output photon number grows roughly like
`(1 + kappa²)(nbar + 1)`. Verifying even the Heisenberg relation
`U† p U = p - kappa x` on the lowest 20 levels at `kappa = 2` needs `N ~ 300`.
Never trust a single-cutoff number:

```python
from ligo_backaction import converged_qfi
res = converged_qfi(lambda N: make_state("cat_even", N, 2.0), spec, rtol=1e-4)
res.value, res.cutoff, res.converged     # <- always check res.converged
```

`suggested_cutoff(nbar, kappa)` gives a starting point for the ladder, never a
substitute for it.

**`kappa` diverges at low frequency** (`kappa ~ 1/Omega²`), so the Fock track
has a low-frequency wall: at the aLIGO-like calibration with
`power_ratio = 1`, `kappa(100 Hz) ~ 48` and no reachable cutoff converges. The
broadband study therefore runs the Fock track over 200–2000 Hz at
`power_ratio = 0.25` (`kappa <= 2.7`) and uses the Gaussian track for the full
band. This is a genuine limitation of the Fock representation for this channel,
not a tuning choice.

**Speed.** The shear, the signal displacement and (when they commute) their sum
are all diagonal in the quadrature eigenbasis, so they are built from one cached
eigendecomposition per cutoff rather than a dense matrix exponential. Loss is
applied in the Fock basis as a shifted-diagonal sum, `O(support * N²)`.

## What the code is not

* The interferometer model is the lossless free-mass input–output relation with
  loss and phase noise bolted on as separate maps — not a full field-propagation
  model with intracavity loss, detuning or signal recycling.
* The two-mode module is a deliberately minimal toy: it locates where the
  per-frequency description breaks, it does not model a real broadband response.
* `optimize_state_for_channel` is a multi-seed *local* search over Fock
  amplitudes; it reports the best local optimum found.
